# LeekWallet Zcash

Experimental DIY Zcash (Ironwood / Orchard / transparent) hardware wallet on the
ESP32-S3-N16R8, built on LeekWallet. The device verifies and signs PCZTs (ZIP 374);
proving happens on the companion.

**Status:** pre-alpha, experimental, not for real funds. eFuses are not burned.

- `firmware/` — device firmware (forked from LeekWallet with history)
- `docs/zcash/` — ANALYSIS, PLAN, ROADMAP
