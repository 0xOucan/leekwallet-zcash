        Passphrase (hidden wallet)

        A passphrase opens a separate wallet from the same seed. The device forgets it on lock, on a wallet switch and on disconnect.

        For Zcash it is a different wallet altogether: the BIP39 passphrase changes the seed, so the board shows another seed fingerprint (ZFP), other addresses and another balance. This app keeps each wallet apart by its fingerprint, so a passphrase wallet never mixes with the one without. Its synced data (what its viewing key has seen, never a key that spends) is kept on this device under that fingerprint: anyone with this device's app data can tell a second wallet was opened here. Forget it in Zcash → Settings when you are done if that matters to you.

        Enter it on the device. Its own keyboard is slower — a long passphrase is a few hundred button presses — and it is the only way the passphrase never leaves the device at all.

        Type it here instead (less safe)

        Typing a passphrase here is weaker than typing it on the device, and the encrypted link does not change that. This app sees every character before anything is encrypted, so anything that has this computer — malware, a screen recorder, a keyboard app that syncs what you type — sees it too. On a phone, your keyboard is part of that risk.

        A wrong passphrase does not fail. It opens a different, empty wallet. The device shows the fingerprint (XFP) of the seed it derived: check it before you use that wallet, and confirm on the device.
